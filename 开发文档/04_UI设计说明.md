---

## 1 设计原则

| 原则 | 说明 |
|---|---|
| 地图优先 | 地图主界面是玩家停留时间最长的界面，其余功能均以浮层或独立页面的形式从地图进入 |
| 单屏单任务 | 抓捕界面为全屏覆盖，进入后不与地图交互，避免操作歧义 |
| 状态可见 | 定位状态、收集进度、任务模式状态在任何界面均可见或可一步到达 |
| 宽容失败 | 定位失败、权限被拒、答错均须给出明确文案与下一步操作，不出现空白页 |
| 借力原生 | 地图、定位、系统权限弹窗尽量使用原生能力与默认样式，降低开发与视觉成本 |

---

## 2 信息架构

```
App
├── 地图主界面（默认首页）
│   ├── 精灵抓捕界面（全屏覆盖，由点击地图精灵进入）
│   └── 任务模式开关（浮层）
├── 图鉴
│   └── 精灵详情
├── 我的精灵（背包）
│   └── 精灵详情
└── 个人中心
    ├── 用户信息
    ├── 收集统计
    └── 权限与任务模式设置
```

底部导航栏固定四项：**地图 / 图鉴 / 我的精灵 / 我的**。

## 3 页面设计

### 3.1 地图主界面

**布局**

```
┌─────────────────────────────┐
│                         ⚙   │  顶部：任务模式指示 / 设置入口
│                             │
│      ○ 精灵                  │
│    ╭───────╮                │
│    │   ◎   │  ← 感知半径     │
│    ╰───────╯     （玩家居中） │
│                  ○ 精灵      │
│                             │
│  ╭───╮                      │
│  │ ⌖ │  ← 回到当前位置        │
│  ╰───╯                      │
│  ╭───────────╮              │
│  │ 开启任务模式 │              │
│  ╰───────────╯              │
├─────────────────────────────┤
│  地图  │  图鉴  │ 我的精灵 │ 我的 │
└─────────────────────────────┘
```

**元素说明**

| 元素 | 说明 |
|---|---|
| 地图 | 全屏二维地图，默认以玩家位置为中心，使用地图 SDK 原生默认样式 |
| 玩家标记 | 玩家当前位置，带方向指示 |
| 感知半径 | 以玩家为中心的半透明圆，半径对应配置值，默认展示值 50 米 |
| 精灵 | 以自身形象（非通用图钉）渲染在地图对应经纬度上；不同稀有度以光环或底座区分 |
| 回到当前位置 | 悬浮按钮，右下或左下角，点击后地图视角回到玩家位置 |
| 任务模式开关 | 悬浮按钮，展示当前任务模式状态（未开启 / 自习中 / 跑步中） |
| 底部导航栏 | 四项，当前项高亮 |

**状态**

| 状态 | 表现 |
|---|---|
| 定位中 | 玩家标记显示加载态，感知半径不显示 |
| 定位失败 | 顶部横幅提示「定位不可用，请检查定位权限」+「去设置」按钮 |
| 权限被拒 | 全屏引导页，说明用途并提供跳转系统设置的按钮，**不得卡死** |
| 附近无精灵 | 无特殊提示，保持地图干净 |
| 任务模式中 | 顶部显示常驻状态条（自习中 / 跑步中 + 已持续时长） |

### 3.2 精灵抓捕界面

**布局**

```
┌─────────────────────────────┐
│  ←                          │
│                             │
│         ╭───────╮           │
│         │       │           │  精灵立绘 + 出场动效
│         │  精灵  │           │
│         ╰───────╯           │
│                             │
│  ┌───────────────────────┐  │
│  │ 题干文字……             │  │
│  ├───────────────────────┤  │
│  │ A. 选项一              │  │
│  │ B. 选项二              │  │
│  │ C. 选项三              │  │
│  │ D. 选项四              │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

**元素说明**

| 元素 | 说明 |
|---|---|
| 精灵立绘 | 居中展示，带出场动效 |
| 题干区 | 展示服务端下发的题目文字，支持 2 行以内 |
| 选项区 | 2–4 个选项，纵向排列，整行可点击，点击热区高度不小于 48dp |
| 返回 | 左上角，退出抓捕返回地图 |

**状态**

| 状态 | 表现 |
|---|---|
| 加载中 | 精灵立绘与题干区骨架占位 |
| 答对 | 选项高亮为成功色 → 捕获成功动效（缩放 + 粒子）→ 1.5 秒后自动返回地图 |
| 答错 | 选项高亮为失败色 → 精灵逃跑动效 → 展示冷却提示文案 → 返回地图 |
| 超时 / 网络失败 | 提示「网络异常，请重试」并提供重试按钮，不消耗机会 |
| 精灵已消失 | 提示「精灵已离开」，返回地图 |

### 3.3 图鉴

**布局**

```
┌─────────────────────────────┐
│  ←  图鉴          已收集 12/30 │
│  ▓▓▓▓▓▓░░░░░░░░░░░  40%      │
├─────────────────────────────┤
│  ┌──────┐ ┌──────┐ ┌──────┐ │
│  │ 立绘 │ │ 立绘 │ │ 剪影 │ │
│  │ 001  │ │ 002  │ │ 003  │ │
│  └──────┘ └──────┘ └──────┘ │
│  ┌──────┐ ┌──────┐ ┌──────┐ │
│  │ 剪影 │ │ 剪影 │ │ 剪影 │ │
│  └──────┘ └──────┘ └──────┘ │
├─────────────────────────────┤
│  地图  │  图鉴  │ 我的精灵 │ 我的 │
└─────────────────────────────┘
```

**元素说明**

| 元素 | 说明 |
|---|---|
| 进度条 | 顶部展示「已收集种类数 / 总种类数」与百分比 |
| 网格 | 三列，已捕获显示立绘与编号，未捕获显示剪影 |
| 分类切换 | 按编号 / 院系 / 属性切换（第一阶段可先只实现按编号） |
| 点击 | 已捕获条目进入精灵详情；未捕获条目点击显示「尚未发现」提示 |

### 3.4 我的精灵（背包）

与图鉴共用网格组件，区别：只展示玩家已拥有的精灵，每个条目右上角显示持有数量角标；顶部提供排序切换（捕获时间 / 地点 / 稀有度）。

### 3.5 精灵详情

展示精灵立绘、名称、编号、属性、稀有度、所属院系 / 地标、首次捕获时间、首次捕获地点（附小地图回显）。

### 3.6 个人中心

展示用户头像与昵称、收集进度统计（已捕获种类数、总捕获次数、稀有精灵数）、权限设置入口、任务模式设置入口。

## 4 视觉规范

### 4.1 色彩

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色 | `#2C7A6B` | 主要按钮、导航高亮、进度条 |
| 主色浅 | `#E6F2EF` | 主色背景、选中态底色 |
| 强调色 | `#F5A623` | 稀有度标识、收集进度高亮 |
| 成功 | `#22C55E` | 答对反馈 |
| 失败 | `#EF4444` | 答错反馈、错误提示 |
| 主文字 | `#1F2937` | 标题与正文 |
| 次文字 | `#6B7280` | 辅助说明、未捕获编号 |
| 分割线 | `#E5E7EB` | 列表分隔 |
| 页面背景 | `#F7F8FA` | 非地图页面底色 |
| 卡片背景 | `#FFFFFF` | 卡片与浮层 |

> 以上为主色方案初稿，UI/美术成员可基于校园视觉识别系统调整，调整后须回写本文档。

### 4.2 字号

| 层级 | 字号 | 用途 |
|---|---|---|
| 大标题 | 24sp | 页面主标题 |
| 标题 | 20sp | 卡片标题、题干 |
| 正文 | 16sp | 选项、正文内容 |
| 辅助 | 14sp | 次要说明 |
| 注释 | 12sp | 编号、角标 |

字体系列使用系统默认字体（Android：Roboto / 思源黑体），不额外引入字体包。

### 4.3 间距与圆角

- 间距采用 4 的整数倍：4 / 8 / 12 / 16 / 24 / 32 dp。
- 页面左右安全边距 16 dp。
- 圆角：按钮 8 dp、卡片 12 dp、浮层 16 dp。
- 卡片阴影 elevation 2，浮层按钮 elevation 4。
- 可点击元素最小热区 48 × 48 dp。

### 4.4 精灵稀有度视觉

| 稀有度 | 视觉表现 |
|---|---|
| 普通 | 无特殊光环 |
| 稀有 | 主色光环 |
| 传说 | 强调色光环 + 出场粒子动效 |

## 5 标注图要求

对地图主界面与精灵抓捕界面两张高保真稿进行前端标注，须包含：

1. 各元素的绝对位置与相对间距（单位 dp）。
2. 字号、字重、行高。
3. 色值（十六进制）。
4. 圆角半径与阴影参数。
5. 可点击区域的范围。
6. 界面在 360 × 800 dp（基准）与 412 × 915 dp 两种常见分辨率下的适配说明。

标注图随设计稿一并提交，作为前端实现的依据。

## 6 切图资源清单

| 资源 | 数量 | 说明 |
|---|---|---|
| 应用图标 | 1 组 | 需提供 48 / 72 / 96 / 144 / 192 dp 各尺寸 |
| 精灵立绘 | 8–12 张 | 透明背景 PNG，统一画布尺寸与风格 |
| 地图上的精灵小图标 | 8–12 张 | 立绘的缩略版本，需在 48 dp 下可辨识 |
| 图鉴剪影 | 复用立绘 | 由立绘转为纯色剪影，无需单独绘制 |
| 按钮与浮层背景 | 若干 | 如需要 |
| 答对 / 答错动效资源 | 2 组 | 帧动画或 Lottie 文件，视实现方案而定 |
| 空态插图 | 2–3 张 | 未收集任何精灵、网络异常等场景 |

**导出要求**：全部位图资源按 @1x / @2x / @3x 三套导出，透明背景资源使用 PNG，动效资源优先使用 Lottie（JSON）以减小体积。
