## 1 什么是 SDK

SDK（Software Development Kit）是第三方提供的一整套现成代码库，开发者直接调用即可，无需从零实现。

地图功能自研几乎不可行——需要地图数据、瓦片切分、渲染引擎、坐标转换、地名标注等完整能力。高德已将其封装为 SDK，调用只需数行代码：

```dart
mapController.setCenter(LatLng(39.99, 116.30));
```

**合规要求**：中国大陆境内展示地图必须使用具备测绘资质的厂商 SDK（高德 / 腾讯 / 百度），不得自行下载地图瓦片渲染。Google Maps 在国内不可用。本约束已写入《软件需求说明书》DC-02。

---

## 2 为什么需要 Key

Key 是服务调用的凭证，作用有三：

1. **身份识别**：高德据此判断请求来自哪个应用，无 Key 直接拒绝。
2. **配额统计**：按 Key 统计调用量，免费额度有限。
3. **防盗用**：绑定包名与签名后，他人拿到 Key 也无法使用。

**没有 Key，地图无法加载，界面为空白。**

---

## 3 需要申请几个 Key

不同平台、不同用途的 Key **不可混用**：

| Key 类型 | 使用方 | 绑定信息 |
|---|---|---|
| Android 平台 SDK | 手机 App | 包名 + 发布版 SHA1 + 调试版 SHA1 |
| Web 服务 | 服务端 | 无需绑定，配额独立 |

本期只需先申请 **Android 平台 SDK** 类型。服务端若需调用逆地理编码等接口，另行申请 Web 服务类型。

---

## 4 申请流程

### 第 1 步：注册与实名认证（关键路径，最慢）

1. 打开高德开放平台控制台：`console.amap.com`
2. 注册账号
3. 完成开发者认证，选择「个人开发者」，需身份证与人脸识别

> ⚠️ **认证需审核，非即时生效。应尽早提交**，否则客户端地图相关工作全部阻塞。审核期间可使用模拟坐标先开发。

### 第 2 步：创建应用

控制台 → 应用管理 → 我的应用 → 创建新应用，填写应用名称（PKMon）与应用类型。

### 第 3 步：添加 Key

在已创建的应用上点击「添加新 Key」，填写：

| 字段 | 填写内容 |
|---|---|
| 应用名称 | PKMon Android |
| 绑定服务 | 勾选 Android 平台 SDK |
| 发布版安全码 SHA1 | 见第 4 步 |
| 调试版安全码 SHA1 | 见第 4 步 |
| Package（应用包名） | 见第 4 步 |

勾选同意服务条款后提交，即可获得 Key。

### 第 4 步：获取包名与 SHA1

**包名**：`android/app/build.gradle` 中的 `applicationId`。

```gradle
defaultConfig {
    applicationId "com.example.pkmon"
}
```

> 若 `AndroidManifest.xml` 中的 `package` 与 `applicationId` 不一致，会报 `INVALID_USER_SCODE` 错误。**以 applicationId 为准。**

**SHA1**：在 Flutter 项目根目录执行：

```bash
cd android
./gradlew signingReport        # Windows 使用 gradlew.bat signingReport
```

在输出中找到 `Variant: debug` 下的 `SHA1:` 一行。**调试版与发布版 SHA1 不同，两者都要填**；将来更换签名证书须回来更新 Key 配置。

## 5 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 地图空白、无报错 | Key 未生效 | 新配置需等待 5–10 分钟 |
| `INVALID_USER_SCODE` | 包名与 applicationId 不一致 | 统一为 applicationId |
| 修改配置后立即测试失败 | 缓存未刷新 | 等待后重启应用 |
| 一个 Key 报错但另一个应用正常 | Key 与应用不匹配 | 一个 Key 只能对应一个应用，多渠道需分别申请 |

---

## 6 安全要求（强制）

1. **Key 不得提交至仓库**。置于本地配置文件，并将该文件加入 `.gitignore`。
2. **不得在群聊、截图、PPT 中暴露完整 Key**。汇报演示如需展示，做打码处理。
3. Key 泄露会导致配额被盗刷，且绑定信息可能被滥用。
